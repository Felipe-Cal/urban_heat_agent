## 2024-05-22 - [Streamlit Toggle Scannability]
**Learning:** Adding emoji prefixes to `st.toggle` labels (e.g., "🌡️ Thermal") significantly improves visual scanning speed for list-heavy interfaces like map layers, compensating for the lack of native icon support in Streamlit toggles.
**Action:** Use emoji prefixes for functional layer controls to improve scannability.
