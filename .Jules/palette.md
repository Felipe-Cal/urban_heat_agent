## 2026-02-26 - [Login/Signup UX Polish]
**Learning:** Streamlit's `st.text_input` supports the `autocomplete` parameter (e.g., `username`, `current-password`, `new-password`), which significantly improves accessibility for password managers. Also, `help` tooltips are effective for inline validation guidance (e.g., password length requirements).
**Action:** Always use `autocomplete` for authentication fields and `help` for complex input requirements to reduce user friction.
